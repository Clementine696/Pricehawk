# AI Agent Documentation

This folder contains all documentation and session logs for AI agents working on the PriceHawk project.

## 📁 Folder Structure

```
ai_sum/
├── README.md                    # This file - overview of AI documentation
├── QUICKSTART.md               # ← 5-minute quick start guide (read first!)
├── SUMMARY.md                   # Main project documentation
├── AI_AGENT_INSTRUCTIONS.md    # Comprehensive guide for AI agents
├── INDEX.md                     # Quick reference index
├── PROJECT_STRUCTURE.md        # Visual codebase structure guide
└── sessions/                    # Session logs organized by date
    ├── TEMPLATE.md             # Session log template
    ├── 2026-01-28.md           # Today's session log
    └── YYYY-MM-DD.md           # Past session logs
```

## 🚀 Quick Start for AI Agents

**New here? Start with**: [QUICKSTART.md](./QUICKSTART.md) - 5-minute guide to get started

Then:
1. **Read First**: [SUMMARY.md](./SUMMARY.md) - Complete project overview
2. **Follow Guidelines**: [AI_AGENT_INSTRUCTIONS.md](./AI_AGENT_INSTRUCTIONS.md) - Development workflow
3. **Check Recent Work**: [sessions/](./sessions/) - Review recent session logs

## 📝 Creating Session Logs

Every work session should have a corresponding log file in `sessions/YYYY-MM-DD.md`

**Template**: See [sessions/2026-01-28.md](./sessions/2026-01-28.md) for example format

**What to include:**
- Tasks completed with file references
- Issues encountered and resolutions
- Files modified
- Next steps/TODOs
- Important notes and decisions

## 🎯 Purpose

This centralized documentation ensures:
- ✅ Consistent development practices across sessions
- ✅ Proper tracking of changes and decisions
- ✅ Easy onboarding for new AI agent sessions
- ✅ Complete audit trail of work done
